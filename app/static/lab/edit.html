How sizes work

Every size is a formula of the piece's overall size, in millimetres: L = left to right, W = front to back, H = height. For example a leg's length can be H - 30, a rail (L - 80) / 2. You can use + - * /, brackets and numbers. Each row is one placed piece: for four legs add four rows (use Copy). Axis says which way the piece's length runs. The position is the piece's lowest corner (x left, y up, z front).
